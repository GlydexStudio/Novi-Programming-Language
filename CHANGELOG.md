# Changelog

All notable changes to Novi are documented here.

## [0.1.0] - 2026-09-25

Initial public developer preview foundation.

### Added

- Novi lexer with source positions and comments.
- Recursive-descent parser and AST.
- Runtime values and lexical environments.
- Interpreter for variables, expressions, functions, returns, conditions and loops.
- Novi-native arrays and objects.
- Property access and `.length` for arrays and strings.
- `novi` CLI with `--help` and `--version`.
- Source-aware Novi errors.
- Runnable language examples.
- Automated lexer, parser and interpreter tests.
